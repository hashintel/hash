`ratio` joins the ad-hoc Variable types in the document type, the persistence schema and the `setVariableType` action; a saved scenario's ratio parameter materializes as a ratio Variable. Synthesis reports an exposed or optimized ratio whose value or bounds leave 0 to 1, and a run-mode edit of a ratio parameter outside that range does not reach the run.
