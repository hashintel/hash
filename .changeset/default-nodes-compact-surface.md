The default (classic) canvas nodes take the compact nodes' colours and shadow. A place is a circle and a transition a square, each showing its name over several lines. Minimap transitions sit on the same footprint as places, where they used to be drawn offset from it. Their outline is a 1.5px ring, a shade heavier than the compact card's border. A node name that is not written in PascalCase keeps all of its words.
