Add `@hashintel/ds-icons`, the HASH animated SVG icon set. It provides `ExperimentalIcon` and named icon components with adjustable stroke weight, hover and click motion, state transitions and reduced-motion support. `experimentalIconPack` maps every `@hashintel/ds-components` icon name to the set for its `IconProvider`. A Panda preset and build info serve hosts that compile the icon styles.
