The preset can now restyle native scrollbars across its theme scope: scroll containers show a rounded thumb on an invisible track, in light and dark mode. The thumb stays hidden until the container is hovered (faded in and out over 200ms; in Safari the reveal is instant and expressed as direct hover rules on the scrollbar pseudo-elements, since WebKit does not re-resolve scrollbar styles when an inherited custom property changes on the container) and shows in the darker shade while the container is being scrolled — by wheel, keyboard, or programmatically. Textareas and selectable lists use a thinner 8px variant. On systems set to always show scrollbars, thumbs stay visible instead. The styling is opt-in: call the new `useCustomScrollbarUI` hook (or `applyCustomScrollbarUI`) once from the component rendering the theme scope root — it gates the CSS via a `ds-custom-scrollbars` class on `<html>`, detects the always-show setting (`ds-scrollbars-visible` class), and tracks scroll activity; apps that never call it keep the browser's default scrollbars. Firefox and other engines without `::-webkit-scrollbar` support fall back to thin standard scrollbars with the same behavior.
