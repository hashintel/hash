- **In the workspace manifest:** `object_store` (milestone 1; it is in the lock file, and the storage pull request for `engine` adds the same line) and `deltalake-core` (milestone 4). Milestone 4 moves `object_store` to 0.13.2, the version `deltalake-core` uses.
- **Two copies of `arrow` and `parquet`:** the workspace has 60, which `duckdb` 1.20000.1 needs, and `deltalake-core` 1.1.4 brings 59. No `duckdb` release uses 59. No arrow data passes between them (`04-sync-table.md`, open points). delta-io/delta-rs#5017 moves Delta to 60.
- **No nightly feature.** `engine` enables five. They served the kinds of DuckDB error, which are left behind (D11).
- **Not needed, although `engine` has them:** `backon`, `bytes`, `opentelemetry`, `zeroize`, and `testcontainers-modules` with `postgres`. They belong to the source readers, the metrics and the secrets.
