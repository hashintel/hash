- **In the workspace manifest:** `object_store` (milestone 1; it is in the lock file, and the storage pull request for `engine` adds the same line) and `deltalake-core` (milestone 4), with a `[patch.crates-io]` entry until a release includes delta-io/delta-rs#5017. Milestone 4 moves `object_store` to 0.14.2, the version `deltalake-core` uses.
- **One copy of `arrow` and `parquet`:** the patched `deltalake-core` uses 60, as `duckdb` 1.20000.1 does.
- **No nightly feature.** `engine` enables five. They served the kinds of DuckDB error, which are left behind (D11).
- **Not needed, although `engine` has them:** `backon`, `bytes`, `opentelemetry`, `zeroize`, and `testcontainers-modules` with `postgres`. They belong to the source readers, the metrics and the secrets.
