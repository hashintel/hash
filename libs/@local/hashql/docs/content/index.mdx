HashQL is a language for working with the entities, types and relationships in a HASH graph.

## Learn the language

The [Introduction][intro] explains its type system, expressions and special forms. Examples show the language's functional and reference notations alongside TypeScript construction.

## Use an SDK

The [TypeScript SDK][sdk-typescript] provides builders for constructing HashQL programs. Its guides cover reusable program construction, a worked graph query, a cheatsheet and troubleshooting, followed by the generated API reference.

TypeScript is the SDK documented here today. Its sidebar selector keeps SDK-specific guides and reference pages together.

For the compiler, query placement and execution model, read [HashQL's technical explanation][hgres-org-hashql].
