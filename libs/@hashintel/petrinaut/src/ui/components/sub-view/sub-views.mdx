A sub-view is a descriptor: an object of type `SubView` that names the components a panel shows as one section or one tab.
The descriptor holds data and component references. The panel decides which descriptors show, and a container draws them.

![A panel chooses descriptors from a sub-views.ts file, and a container renders the components they name](./sub-views.d2)

## Entry point

`SubView` in `ui/components/sub-view/types.ts` is the interface. A panel keeps its descriptors in a `sub-views.ts` file beside its entry file, one exported constant per sub-view.

Two containers render descriptors:

- `VerticalSubViewsContainer` stacks them as sections. The left sidebar and every properties panel use it.
- `HorizontalTabsHeader` and `HorizontalTabPanel` draw a tab bar and the panel of the active tab. The bottom panel uses them.

## Interface

| Field | What it sets |
| --- | --- |
| `id`, `title`, `tooltip`, `icon` | The identity of the section or tab and what its header shows |
| `component` | The content |
| `headerAction` | A component at the right of the header, such as an add button |
| `titleComponent` | A component that replaces the title text of a `main` sub-view |
| `main` | A fixed header that does not collapse |
| `defaultCollapsed`, `resizable`, `canMaximize` | How a section opens, resizes and fills its container |
| `retainOnCollapse` | A visited section stays mounted while collapsed |
| `headerActionMutates` | The action is hidden where the presentation hides mutation actions |

`createDeferredSubView` builds a descriptor whose components arrive through a dynamic import. The first reader to mount starts the load, and `preload` starts it earlier.

## Data flow

A user collapses a section of the properties panel:

1. The panel entry, for example `PlaceProperties`, chooses a list from its `sub-views.ts` and passes it as `subViews` with a container `name`.
2. `VerticalSubViewsContainer` renders each open section through the `component` and `headerAction` of its descriptor.
3. A click on a header calls `updateSubViewSection`, which saves `collapsed` under the container name in the [user settings](layer:react.state). A resize saves `height` the same way, 300 ms after the last change.
4. The container renders again. The collapsed section unmounts its content, unless `retainOnCollapse` is set and the section was opened before.

Maximizing a section does not go through the settings. The container writes `expandedSubView` to the [navigation state](layer:react.navigation), so Back and Forward restore it.

A plugin's `bottomPanelViews` entry never becomes a `SubView`. `usePluginBottomPanelViews` turns it into a tab with the same `id`, `title` and `tooltip`, and the bottom panel lists it after its own tabs. See [Writing a plugin](doc:ui.plugins/writing-a-plugin).

## Rules

**A descriptor file is a `.ts` file.** A module that exports an object beside a component loses Fast Refresh: every save re-runs its importers and resets their state. `tsc` rejects JSX in a `.ts` file, so a component cannot be written there.

**A descriptor names components, not render functions.** A component field keeps the descriptor free of closures, and the container renders it as an element that React can keep between renders. The deprecated `renderHeaderAction` and `renderTitle` fields still render. No lint rule checks this; `deferred-sub-view.test.tsx` reads the action as a component.

**The maximize animation changes `transform` and `clip-path` only.** The section is laid out once at the size of the container, then moved and clipped, so its content is not laid out again on each frame. The test "animates how the section is drawn in both directions" in `vertical-sub-views-container.test.tsx` holds this.

**A section that holds a code editor sets `retainOnCollapse`.** Creating a Monaco editor costs more than keeping one, so a visited section keeps its editor while collapsed. The test "retains visited code while collapsed" in the same file holds this. See [Monaco](doc:ui.monaco/monaco).

## Pitfalls

- A panel that builds a descriptor during render, as `PlaceProperties` does to add the place name to the title, must spread a constant from `sub-views.ts`. A descriptor with a component defined during render remounts that component on every render.
- The `id` is the key of the saved collapse state and height. Renaming it discards what users saved.
