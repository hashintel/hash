## Implementation boundaries

Candidate lookup is separately labelled `unsettled-candidate`, identifies only exact hash/UTF-16 length/UTF-8 size, emits no candidate revision ID/ordinal and does not replace `currentWorkpiece`. Current lookup carries the actual settled identity and checks its hash. No-current lookup is unavailable, not an invented empty document. Bounds: 16 query texts, 4,096 UTF-16 units per text, 32 returned matches per query; total/omitted counts disclose incomplete results. Duplicate and overlapping occurrences are ordered deterministically. No whitespace, newline or Unicode normalization is performed.

Only unique unchanged text at the same revision-local span carries a relation automatically, with source authorization checked again. Moves, changed text, duplicate ambiguity, split/merge, deletion and reintroduction do not acquire guessed continuity. This is the Mission's **partial, revision-local fallback**, not a passage graph or introduced-by claim. See [dispositions.md](dispositions.md).
