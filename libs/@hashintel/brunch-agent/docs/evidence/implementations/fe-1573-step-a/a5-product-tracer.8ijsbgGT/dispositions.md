## Passage policy: explicit partial branch

| Case | Observed mechanism / oracle | Disposition |
| --- | --- | --- |
| Immutable current/candidate locators | Built read tool supplies exact hash-scoped UTF-16 spans; candidate/current/no-current are distinct; pure locator tests cover CRLF, combining characters, emoji, missing text, duplicate/overlapping matches and explicit limits | Pass for the bounded locator affordance; no relevance or identity claim |
| Unchanged carried text | Unique text remains at the same span; sources reauthorize; new successful output retains the relation even when new raw input omits evidence | Pass for this exact carry rule through mounted state and browser superseded-why |
| Duplicate headings / quotes | Literal lookup returns distinct occurrences; automatic carry refuses duplicate ambiguity; explicit revision-local selection remains possible | No guessed heading identity, quote identity or source relevance |
| Rename / move | Tested changed heading length or prefix moves the span; no inferred relation is carried | Unsupported continuity; a new revision-local lookup/declaration is required. An unchanged unique same-span relation does not establish an introduced-by identity |
| Paraphrase | Changed wording does not inherit a relation by fuzzy similarity | Continuity unsupported/refused |
| Split / merge | Changed passage text has no invented predecessor/successor set | Continuity unsupported under the Mission's revision-local fallback |
| Delete / reintroduction | Deleted relations are not restored from an older revision; reintroduced text is not automatically supported | No identity reuse or introduced-by claim; no passage graph |
| Overbroad basis | A full-document locator does not acquire narrower relations; the unit oracle returns temporal-context-only and no relations | Mechanical refusal of inherited narrower support; semantic breadth/relevance quality still unassessed |

`packages/core/test/workpiece-evidence.test.ts`, `workpiece-locators.test.ts`, the built source integration and app `test/reconciliation.test.ts` are the executable mapping for the prospective passage/evidence oracles. A split/merge graph and retirement epoch system were deliberately not invented. This is **Partial**, not an all-classes passage-policy pass.
