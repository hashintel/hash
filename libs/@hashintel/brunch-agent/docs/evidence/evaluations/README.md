# Evaluation evidence

Immutable artifacts from observed evaluation campaigns. Campaign directories are named for the
case and instrument, rather than repeating a generic process-model hierarchy.

- `vestera-legacy-baseline/` — historical conditions 1, 2, 4, and 5.
- `vestera-runbook-headless/` — Mission 3 headless-runbook drives.
- `vestera-ir-quality-calibration-v1/` — the four calibration reviews and adjudication.
- `vestera-prospective-baseline-v1/` — reserved for the three-run prospective baseline; no run has been executed yet.

Do not place prompts, runners, cases, or answer keys here; those live in
[`evaluations/`](../../../evaluations/). Never overwrite an observed artifact. An older campaign
is evidence, not an active instrument. A documented path relocation may rebase Markdown links,
but does not change captured claims or raw payload fields.
