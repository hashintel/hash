## Installation

1. Install the package.

```sh
npm install @hashintel/ds-components
```

2. Import the component.

```tsx
import { ReorderableList } from "@hashintel/ds-components";

export const VisibleColumnsList = ({ columns, onChange }) => (
  <ReorderableList aria-label="Visible columns" onChange={onChange}>
    {columns.map((column) => (
      <ReorderableList.Item
        key={column.id}
        id={column.id}
        label={column.name}
      >
        {column.name}
      </ReorderableList.Item>
    ))}
  </ReorderableList>
);
```

### When to use

### When not to use

<DontList
  items={[
    "Don't use it to order items by a property (name, date, relevance), that's sorting. Use SortMenu or a sortable column header.",
    "Don't use it to move items between two lists or into groups. It reorders within a single list only.",

## Anatomy

```tsx
<ReorderableList onChange={onChange}>
  <ReorderableList.Item id="row-1" label="Row one">
    {/* row content */}
  </ReorderableList.Item>
</ReorderableList>
```

Each item renders its drag handle automatically; the item's children fill the
rest of the row.

## Examples

### Basic

The order is controlled: render the items in your state's order and update
that state in `onChange`, which receives the full id list in its new order.

## Behavior

- The order is controlled: the list never moves rows itself. Apply the
  `onChange` results to your state, or the rows spring back on drop.
- Dragging starts only from the handle and is locked to the list's vertical
  axis and bounds, so row content keeps its own pointer interactions.
- Dropping outside a valid position, or pressing Escape mid-drag, cancels the
  reorder.
- In a scrollable container, dragging toward an edge scrolls the list.

## Accessibility

Reordering is fully keyboard-operable through the handle, and every pick-up,
move, and drop is announced to screen readers with the row's position.

### What ReorderableList provides

- Each handle is a real button named "Reorder \{label\}", with instructions
  for operating it attached via `aria-describedby`.
- Announcements name rows by `label` and speak positions ("Email address
  moved to position 2 of 3").

### What you must do

- Write each item's required `label` as a user would name the row (ex: "Email
  address", not an id).
- Give the list an `aria-label` (or `aria-labelledby`) describing the
  collection.

### Keyboard

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Focus a row's drag handle |
| <kbd>Space</kbd> / <kbd>Enter</kbd> | Pick up the row; press again to drop it |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Move the picked-up row |
| <kbd>Esc</kbd> | Cancel and restore the original position |
