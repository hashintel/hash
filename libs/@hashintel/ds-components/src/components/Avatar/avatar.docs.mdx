## Examples

### Basic

`alt` names the subject and becomes the accessible name; `placeholder` is required because it shows while the image loads and whenever `src` is missing or fails.

<Stage>
  <Avatar
    alt="Chris Feijoo"
    src="https://avatars.githubusercontent.com/u/2991143?v=4"
    placeholder={{ initials: "CF" }}
  />
  <Avatar alt="Maya Iyer" placeholder={{ initials: "MI" }} />
</Stage>

### Placeholders

Pick the placeholder that best identifies the subject: `initials` for anyone with a name, `icon` where there is no particular person, and `custom` for an arbitrary node such as an emoji. Initials are capped at two characters and uppercased.

<Stage>
  <Avatar alt="Chris Feijoo" placeholder={{ initials: "CF" }} />
  <Avatar alt="Deactivated user" placeholder={{ icon: "user" }} />
  <Avatar alt="Biology lab web" placeholder={{ custom: "🧪" }} />
</Stage>

### Image fallback

A failed image falls back to the placeholder — there is no broken-image state. Assigning a new `src` retries, even for a URL that failed before.

<Stage>
  <Avatar
    alt="Chris Feijoo"
    src="https://avatars.githubusercontent.com/u/2991143?v=4"
    placeholder={{ initials: "CF" }}
  />
  <Avatar
    alt="Chris Feijoo"
    src="data:image/png;base64,thisisnotavalidpngpayload"
    placeholder={{ initials: "CF" }}
  />
</Stage>

### Sizes

Five fixed sizes run from `xxs` to `lg`; `md` is the default. Use `xxs`–`sm` in dense chrome such as table rows and comment threads, and `lg` for profile headers.

<Stage>
  <Avatar size="xxs" alt="Chris Feijoo" placeholder={{ initials: "CF" }} />
  <Avatar size="xs" alt="Chris Feijoo" placeholder={{ initials: "CF" }} />
  <Avatar size="sm" alt="Chris Feijoo" placeholder={{ initials: "CF" }} />
  <Avatar size="md" alt="Chris Feijoo" placeholder={{ initials: "CF" }} />
  <Avatar size="lg" alt="Chris Feijoo" placeholder={{ initials: "CF" }} />
</Stage>

### Custom size

`size="custom"` hands the scale to a `--avatar-size` you set via `className` — the box, border width, corner radius, and placeholder type all derive from that one variable.

```tsx
import { css } from "@hashintel/ds-helpers/css";

import { Avatar } from "@hashintel/ds-components";

const profileHeroSize = css({ "--avatar-size": "96px" });

export const ProfileHero = () => (
  <Avatar
    size="custom"
    className={profileHeroSize}
    alt="Chris Feijoo"
    placeholder={{ initials: "CF" }}
  />
);
```

### Shapes

Use `circle` (the default) for people and `square` for everything else — organizations, webs, services. The square's corner radius scales with the avatar's size.

<Stage>
  <Avatar
    shape="circle"
    alt="Chris Feijoo"
    placeholder={{ initials: "CF" }}
  />
  <Avatar shape="square" alt="HASH" placeholder={{ initials: "H" }} />
</Stage>

### Tones

Tone only styles the placeholder — once an image loads, every tone shows the same neutral fill and border.

<Stage>
  <Avatar
    tone="neutral"
    alt="Chris Feijoo"
    placeholder={{ initials: "CF" }}
  />
  <Avatar tone="brand" alt="Chris Feijoo" placeholder={{ initials: "CF" }} />
</Stage>

### With tooltip

Wrap the avatar in a Tooltip to reveal the name on hover and focus when no visible label sits beside it. The tooltip also makes a static avatar keyboard-focusable, so the name isn't hover-only.

```tsx
import { Avatar, Tooltip } from "@hashintel/ds-components";

export const AssigneeAvatar = () => (
  <Tooltip content="Chris Feijoo">
    <Avatar size="sm" alt="Chris Feijoo" placeholder={{ initials: "CF" }} />
  </Tooltip>
);
```

## Behavior

- The image loads hidden behind the placeholder and only appears once complete — there is never an empty box, and already-cached images show immediately.
- Images draw on a white backing, so transparent logos don't pick up the tone fill; they can't be dragged and send no referrer.
- Initials longer than two characters are truncated, and all initials render uppercase.

## Content

- Write `alt` as the subject's name as it appears elsewhere in the product: "Chris Feijoo", "HASH". Append state only when the avatar shows it: "Chris Feijoo (online)".
- Give people two initials (first and last name) and organizations or webs their first letter.

## Accessibility

### What Avatar provides

- A static avatar renders `role="img"` named by `alt`; the inner image is decorative (empty `alt`), so screen readers announce the name exactly once.
- With `onClick` or `href` it renders a native `<button>` or `<a>`, also named by `alt`, with a visible focus ring.

### What you must do

- `alt` is the entire accessible name — make it identify the subject, and, for interactive avatars, where pressing leads.
- Keep a meaningful `alt` on interactive avatars even when the name is shown beside them — the adjacent text isn't associated with the button or link. For a non-interactive avatar that's redundant with an adjacent name, pass `aria-hidden` instead of emptying `alt`.
