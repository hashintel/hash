## Installation

1. Install the package.

```sh
npm install @hashintel/ds-components
```

2. Import the component.

```tsx
import { useState } from "react";

import { Select } from "@hashintel/ds-components";

export const EntityTypePicker = () => {
  const [entityType, setEntityType] = useState<string | null>(null);

  return (
    <Select
      placeholder="Select an entity type…"
      items={[
        { value: "person", text: "Person" },
        { value: "organization", text: "Organization" },
        { value: "document", text: "Document" },
      ]}
      value={entityType}
      onChange={setEntityType}
    />
  );
};
```

## Anatomy

Select is a single component — its parts are configured through props and the
`items` data rather than composed as JSX parts:

- trigger — the field that opens the dropdown and anchors it, showing the
  `placeholder` or the current selection, with an optional `prefix` and a
  clear button while the selection is clearable.
- `items` — the dropdown's content: options (`{ value, text }`), mixed freely
  with labelled groups. In a multi select, items additionally take `suffix`,
  `showOnlyButton`, `selectedStyle` and `selectedTone` — see
  [Item suffixes and selection styles](#item-suffixes-and-selection-styles).
- search field — pinned atop the dropdown when `searchable`, filtering the
  items by their text.
- selection summary — in a searchable multi select, an "x of y" count and a
  "Select all" / "Clear all" toggle beneath the options.

```tsx
<Select
  placeholder="Select a property type…" // trigger text before a selection
  prefix={{ iconName: "search" }} // leading icon, text or custom node
  searchable // search field atop the dropdown
  items={[
    { value: "text", text: "Text" }, // an option
    {
      id: "numeric",
      label: "Numeric", // a group heading (not selectable)
      items: [
        { value: "number", text: "Number" },
        { value: "integer", text: "Integer" },
      ],
    },
  ]}
  value={value}
  onChange={setValue}
/>
```

### Custom rendering

`renderItem` controls how options render in the dropdown and doubles as the
trigger's renderer; `renderSelectedItem` overrides the trigger alone. Keep the
item's text in the output so options keep their accessible names.

export const customRenderingCode = `import { useState } from "react";

import { Select } from "@hashintel/ds-components";

const runStatuses = [
  { value: "running", text: "Running" },
  { value: "succeeded", text: "Succeeded" },
  { value: "failed", text: "Failed" },
] as const;

type RunStatus = (typeof runStatuses)[number]["value"];

const statusColor: Record<RunStatus, string> = {
  running: "#0775e3",
  succeeded: "#1a9338",
  failed: "#d13617",
};

const renderStatus = (value: RunStatus) => (
  <span style={{ display: "flex", alignItems: "center", gap: 8 }}>
    <span
      aria-hidden="true"
      style={{
        width: 8,
        height: 8,
        borderRadius: "50%",
        background: statusColor[value],
      }}
    />
    {runStatuses.find((option) => option.value === value)?.text}
  </span>
);

export const RunStatusSelect = () => {
  const [status, setStatus] = useState<RunStatus | null>("running");

  return (
    <Select
      width="sm"
      items={runStatuses}
      value={status}
      onChange={setStatus}
      renderItem={renderStatus}
      aria-label="Run status"
    />
  );
};`;

export const CustomRenderingDemo = () => (
  <DemoState data-harness>
    <Select
      width="sm"
      items={[
        { value: "running", text: "Running" },
        { value: "succeeded", text: "Succeeded" },
        { value: "failed", text: "Failed" },
      ]}
      value="succeeded"
      onChange={noop}
      renderItem={(value) => (
        <span style={{ display: "flex", alignItems: "center", gap: 8 }}>
          <span
            aria-hidden="true"
            style={{
              width: 8,
              height: 8,
              borderRadius: "50%",

                value === "running"

                  : value === "succeeded"

                    : "#d13617",
            }}
          />
          {value === "running"
            ? "Running"
            : value === "succeeded"
              ? "Succeeded"
              : "Failed"}
        </span>
      )}
      aria-label="Run status"
    />
  </DemoState>

## Behavior

- The menu's content mounts renders in a portal above the page, preventing most z-index + overflow issues.
- Selected values missing from `items` render as disabled options at the top
  of the list, so a committed selection always stays visible — except while
  `loading` with no options yet.
- "Select all" selects every enabled option — regardless of the active search
  filter.
- `defaultOpen` is read once on mount and doesn't fire `onOpenChange`.

## Content

- Option text is a 1–4 word noun phrase, sentence case, no punctuation:
  "Person", "Created at", "Last 30 days". Name values, not actions — actions
  belong in Menu.
- Keep option text unique and front-load the distinguishing word, so the list
  scans and typeahead works.
- Order options by the likeliest choice, numerically, or alphabetically — one
  scheme per list.
- Placeholders follow "Select a [noun]…" and never carry requirements — they
  disappear once a value is chosen.
- Group labels are 1–2 word category nouns: "System types", "Numeric".
- Write `emptyState` as why plus next step: "No properties yet — add one in
  the type editor."

## Accessibility

Select implements the
[WAI-ARIA listbox pattern](https://www.w3.org/WAI/ARIA/apg/patterns/listbox/),

### What Select provides

- A real `<button>` trigger with listbox popup semantics, arrow-key navigation
  and typeahead.
- A hidden native `<select>` mirrors the selection so forms submit it under
  `name`.
- Inside a `Form.Field` the trigger adopts the field's label id automatically.
- The dropdown's search field and the clear button carry built-in labels
  ("Search options", "Clear input").

### What you must do

- Give every select an accessible name: a `Form.Field` label, or `aria-label`
  where no label is visible (toolbars, `naked` selects). A placeholder is not
  a label.
- With `variant="naked"`, supply your own focus affordance — the variant
  strips hover and focus styles.
- Keep the item's text in `renderItem` output and mark decorative nodes
  `aria-hidden`, so options keep their accessible names.

### Keyboard

Select adds handling beyond the listbox pattern:

| Key                      | Action                                                                                                                                       |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| Escape (multi select)    | Closes the dropdown and reverts the selection to its state when it opened.                                                                   |
