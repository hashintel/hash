## Installation

1. Install the package.

```sh
npm install @hashintel/ds-components
```

2. Import the component.

```tsx
import { Button, Menu } from "@hashintel/ds-components";

export const EntityActionsMenu = () => (
  <Menu
    trigger={
      <Button variant="subtle" iconName="chevronDown" iconPosition="right">
        Entity actions
      </Button>
    }
    items={[
      { text: "Edit entity", icon: "pencil", onClick: () => {} },
      { text: "Duplicate entity", icon: "copy", onClick: () => {} },
    ]}
  />
);
```

<DoList

### When not to use

<DontList

## Anatomy

Menu has no JSX parts; everything is expressed through props. `items` mixes
action, link, and submenu items with labelled groups and custom rows:

```tsx
<Menu
  // Any element accepting aria-expanded; press to open
  trigger={<Button>Actions</Button>}
  // Pinned above/below the items, outside the scrollable area
  header={<span>Header</span>}
  footer={<span>Footer</span>}
  items={[
    { text: "Action item", icon: "pencil", onClick: (id) => {} },
    { text: "Link item", href: "/entities" },
    {
      text: "Submenu item",
      subItems: [{ text: "Nested action", onClick: (id) => {} }],
    },
    {
      id: "group",
      label: "Group label",
      items: [{ text: "Grouped action", onClick: (id) => {} }],
    },
    { custom: <span>Custom row</span> },
  ]}
/>
```

Selection is yours to control: store the chosen ids and rebuild `items` from
them.

```tsx
import { useState } from "react";

import { Button, Menu, type MenuItem } from "@hashintel/ds-components";

const columns = ["Name", "Type", "Created by", "Last edited"];

export const ColumnsMenu = () => {
  const [visible, setVisible] = useState(["Name", "Type"]);
  const toggleColumn = (id: string) =>
    setVisible((previous) =>
      previous.includes(id)
        ? previous.filter((column) => column !== id)
        : [...previous, id],
    );
  return (
    <Menu
      trigger={
        <Button variant="subtle" iconName="table">
          Columns
        </Button>
      }
      items={columns.map((column): MenuItem => ({
        text: column,
        selectedStyle: "checkbox",
        selected: visible.includes(column),
        keepOpenOnSelect: true,
        onClick: toggleColumn,
      }))}
    />
  );
};
```

### EllipsisMenu

EllipsisMenu is Menu with a ready-made icon-button trigger — the standard
overflow affordance for table rows and cards. It defaults to the `ellipsis`
icon, a `subtle` Button, `bottom-end` placement, and an accessible name of
"Actions"; `iconName`, `variant`, and `size` restyle the trigger. With
`disabled` (or an empty `items` array) it renders a disabled trigger.

<Stage>

    items={[
      { text: "Edit entity", onClick: () => {} },
      { text: "Duplicate entity", onClick: () => {} },
      { text: "Delete entity", tone: "error", onClick: () => {} },

  />

    iconName="bell"
    variant="solid"
    size="xs"

## Behavior

- The menu's content mounts when first opened, unmounts when closed, and
  renders in a portal above the page.
- While open, the trigger carries `aria-expanded` and a Button trigger also
  shows its pressed visual.
- Selecting an item closes the menu unless that item sets `keepOpenOnSelect`.
- Width hugs the widest item, between `140px` and `min(500px, 70vw)`. Height
  caps at the space available on the menu's side of the trigger, and the items
  scroll beyond it.
- A tall `header`/`footer` stays pinned while the items scroll, and can only
  squeeze the items area down to `200px` (or the list's natural height, when
  shorter).
- With an empty `items` array, Menu renders just the trigger with no menu
  behind it; EllipsisMenu disables its trigger instead.
- Arrow keys wrap from the last item to the first (and back) on discrete
  presses, but a held key stops at the boundary instead of cycling.

## Content

- Label the trigger with the scope of the actions — "Entity actions", not
  "Menu" or "Options".
- Write item labels verb-first, 1–3 words, sentence case: "Edit entity",
  "Duplicate", "Copy entity ID". No punctuation.
- Name the object when the menu mixes targets — "Delete property" beats
  "Delete" when nearby items act on the entity.
- Keep `description` to one short clause of consequence or context, not a
  restatement of the label.
- Group labels are 1–2 word nouns: "View", "Manage", "Danger zone".
- Order items by expected frequency of use, destructive actions last in their
  own group.
- Keep menus under roughly 12 items — beyond that, group them or switch to a
  searchable Combobox.

## Accessibility

Menu implements the
[WAI-ARIA menu button pattern](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button/);
the interaction model comes from the underlying
[Ark UI Menu](https://ark-ui.com/docs/components/menu).

### What Menu provides

- The trigger is wired with `aria-haspopup` and `aria-expanded`; closing the
  menu returns focus to it. The open-state pressed visual on Button triggers
  is visual only — no `aria-pressed` is set.
- Items expose menu-item semantics; `selectedStyle="checkbox"` items render
  as menu item checkboxes announcing their checked state, and `href` items
  render real `<a>` elements.
- Disabled and loading items are exposed as disabled and skipped by arrow-key
  navigation.
- Item `icon`s are `aria-hidden`; EllipsisMenu's trigger has a built-in
  accessible name, "Actions".

### What you must do

- Give a hand-rolled icon-only trigger an accessible name scoped to its
  object — `tooltip="Entity actions"` or an equivalent `aria-label`.
- Make every label carry its full meaning without the icon — icons are not
  announced to screen readers.
- Provide an explicit `id` when `text` is JSX; the id is also what `onClick`
  and `onKeyDown` report.

### Keyboard

Two behaviors deviate from the standard pattern:

| Key                     | Action                                                                                                                                                                                                                                 |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ArrowDown` / `ArrowUp` | Moves the highlight. A discrete press at the last/first item wraps to the opposite end; a held key stops at the boundary instead of cycling.                                                                                           |
| `Tab` / `Shift+Tab`     | When the menu has a focusable `header`, `footer`, or custom row, moves between those rows and the item list. Past either edge the menu closes — `Tab` hands focus to the element after the trigger, `Shift+Tab` to the trigger itself. |

## API reference

### Menu

<PropsTable of={Menu} defaults={{ position: '"bottom-start"' }} />

### Menu items

Entries in `items` (and in `subItems`) are items, labelled groups, or custom
rows:

```ts
type MenuEntry = MenuItem | Group | CustomRow;

type MenuItem = {
  /** Optional when `text` is a plain string, which then doubles as the id. */
  id?: string;
  text: React.ReactNode;
  /** One line of secondary text under the label. */
  description?: React.ReactNode;
  icon?: IconName;
  /** Trailing content, e.g. a count. */
  suffix?: React.ReactNode;
  /** Indents the row by this many steps. */
  indent?: number;
  disabled?: boolean;
  /** Shows a spinner and makes the item inert. */
  loading?: boolean;
  tone?: "neutral" | "brand" | "error";
  /** Marks the item as the current choice. */
  selected?: boolean;
  /** How `selected` is shown. Default: "highlight". */
  selectedStyle?: "tick" | "checkbox" | "highlight";
  /** Tone of the selected state, when it differs from `tone`. */
  selectedTone?: "neutral" | "brand" | "error";
  /** Keeps the menu open when this item is selected. */
  keepOpenOnSelect?: boolean;
} & (
  | { onClick: (id: string) => void } // action
  | { href: string; target?: "_blank" } // link
  | { subItems: MenuEntry[]; menuClassName?: string } // submenu
);

type Group = {
  id: string;
  label: React.ReactNode;
  items: Array<MenuItem | CustomRow>;
};

/** Presentational row: never highlighted, Tab reaches focusable children. */
type CustomRow = { id?: string; custom: React.ReactNode };
```
