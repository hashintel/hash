## Installation

1. Install the package.

```sh
npm install @hashintel/ds-components
```

2. Import the component.


## Anatomy

```tsx
<Drawer onClose={close}>
  <Drawer.Header title="Title" description="Supporting text" />
  <Drawer.Body>Content</Drawer.Body>
  <Drawer.Footer actions={<Button>Confirm</Button>} />
</Drawer>
```

`Drawer.Body` is required; `Drawer.Header` and `Drawer.Footer` are optional,
and the types enforce this order. A drawer without a header still renders the
close button in an empty header row.

`"closeButtonAndOverlay"` closes on the close button, Escape, a backdrop
click, and an edge swipe; `"closeButton"` drops the backdrop click, protecting

close the drawer.

### Swapping drawers in place

Give drawers that occupy the same slot a shared `swapKey`: switching between
them replaces the panel content in place instead of sliding out and back in.
The first drawer in a slot still animates in.

```tsx
import { useState } from "react";

import { Button, Drawer } from "@hashintel/ds-components";

const entities = ["Alice Chen", "Acme Corp", "Bay Area Lab"];

export const EntityInspector = () => {
  const [selected, setSelected] = useState<string | null>(null);

  return (
    <>
      {entities.map((entity) => (
        <Button key={entity} onClick={() => setSelected(entity)}>
          {entity}
        </Button>
      ))}
      {entities.map((entity) =>
        selected === entity ? (
          <Drawer
            key={entity}
            swapKey="entity-inspector"
            showBackdrop={false}
            onClose={() => setSelected(null)}
          >
            <Drawer.Header title={entity} description="Entity properties" />
            <Drawer.Body>
              <p>Properties and links for {entity}.</p>
            </Drawer.Body>
          </Drawer>
        ) : null,
      )}
    </>
  );
};
```

### Initial and return focus

By default the drawer focuses its first tabbable element on open and returns
focus to the previously focused element on close. Pass `initialFocusRef` to
focus a specific control instead, and `returnFocusRef` when the original
element will be gone by the time the drawer closes.

```tsx
import { useRef, useState } from "react";

import { Button, Drawer, TextInput } from "@hashintel/ds-components";

export const RenameWorkspaceButton = () => {
  const [open, setOpen] = useState(false);
  const [name, setName] = useState("Acme research");
  const nameInputRef = useRef<HTMLInputElement>(null);

  return (
    <>
      <Button onClick={() => setOpen(true)}>Rename workspace</Button>
      {open ? (
        <Drawer initialFocusRef={nameInputRef} onClose={() => setOpen(false)}>
          <Drawer.Header title="Rename workspace" />
          <Drawer.Body>
            <TextInput
              inputRef={nameInputRef}
              value={name}
              onChange={setName}
            />
          </Drawer.Body>
        </Drawer>
      ) : null}
    </>
  );
};
```

## Behavior

- The panel never covers the whole viewport — a slice of the opposite edge
  always stays clear so the page behind remains visible.
- Swipe-to-close starts only from a thin strip along the panel's inner edge,
  so content inside the panel stays selectable and draggable.
- Mounting a second drawer while one is open stacks it. Try to keep stacks no more than two deep — deeper nesting disorients users.

## Content

- Title the drawer with the object or task it shows, 1–4 words, sentence case:
  "Entity history", "Edit entity type". No terminal punctuation.
- Use `description` for one line of context ("Person · updated 2 hours ago"),
  not instructions — those belong in the body.
- Footer labels follow Button content rules: verb-first, 1–3 words, with the
  confirming action in `actions` and destructive or escape actions in
  `secondaryActions`.

## Accessibility

Drawer implements the
[WAI-ARIA dialog pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/).

### What Drawer provides

- Dialog semantics, with the `Drawer.Header` `title` and `description` wired
  up as the accessible name and description.
- With the backdrop (the default) the drawer is modal: focus is trapped inside
  and Escape closes it. The built-in close button is labelled "Close drawer".
- On close, focus returns to the element focused before it opened — or to
  `returnFocusRef` when set.
- `loading` sets `aria-busy` on the panel and renders the spinner overlay in a
  polite live region.

### What you must do

- Name the drawer when the header is custom or absent — pass `aria-label`,
  since there is no title to announce.
- Always render your own close action when `shouldCloseOn="none"` — it removes
  the close button, Escape, and swipe, so without one the user is stranded.
- Reserve `showBackdrop={false}` for ancillary panels — focus is not trapped,
  so the surrounding page's tab order must still make sense.

## Styling


The preset sizes apply as `maxWidth` (left/right) or `maxHeight` (top/bottom)
on the panel, so for a custom size override those values through `className`. 

```tsx
import { css } from "@hashintel/ds-helpers/css";

const narrowPanel = css({ maxWidth: "[480px]" });

// …
<Drawer className={narrowPanel} onClose={close}>
  <Drawer.Header title="Quick filters" />
  <Drawer.Body>
    <p>A narrower panel for a short form.</p>
  </Drawer.Body>
</Drawer>;
```
