## Why Inter

Inter's simplicity, clarity and open forms make it the right functional
typeface for HASH. Always default to Inter: it is what every product already
renders in, it stays legible at the 12–14px sizes most of our interfaces use,
and its tabular figures line up in tables and data. Headings use Inter
Display, the display cut of the same family; code uses Geist Mono.

## Rules

- Use the display family for headings and titles, the body family for
  interface and running text, and the mono family for code and token names.
- Use three weights only: 400 (`normal`), 500 (`medium`) and 600 (`semibold`).
- Control text follows control size: `xs` and `sm` controls use the text style
  of the same name; `md` and `lg` controls use `base`.
- Line height tightens as size grows, and letter spacing goes from slightly
  open at the small end to tight at the largest sizes.
- Use `fg.body` or stronger for text people must read. `fg.subtle` and
  `fg.muted` are below 4.5:1 on the page ground.

### Weights

| Token                 | Value | Figma variable    |
| --------------------- | ----- | ----------------- |
| `fontWeights.normal`   | 400   | `weight/normal`   |
| `fontWeights.medium`   | 500   | `weight/medium`   |
| `fontWeights.semibold` | 600   | `weight/semibold` |

### Line height and spacing

| Sizes             | Line height | Letter spacing              |
| ----------------- | ----------- | --------------------------- |
| `xxs`, `xs`, `sm` | 1.6em       | Slightly open, from +0.01em |
| `base`, `lg`      | 1.5em       | —                           |
| `xl`, `2xl`       | 1.4em       | —                           |
| `3xl`, `4xl`      | 1.3em       | Tight, to −0.025em at `4xl` |

The leading factor rescales every line height: tight 0.9, normal 1, loose 1.1.
