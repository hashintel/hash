## Using spacing tokens

Spacing tokens apply to every padding, margin, gap, and inset property. One
unit is 4px at normal density; the rhythm keeps unrelated screens feeling
consistent.

```tsx
import { css } from "@hashintel/ds-helpers/css";

export const PropertyRow = () => (
  <div className={css({ display: "flex", gap: "2", px: "4", py: "2" })}>
    …
  </div>
);
```

With `strictTokens` enabled, off-scale values must be explicit escapes:
`width: "[64px]"`. Treat every escape as a flag that the design may be
off-rhythm.

## The scale

Token names are multiples of the 4px base unit: `1` = 4px, `2` = 8px, `4` =
16px. Half steps add 2px precision at the small end. Values are shown at
normal density.

| Token | Size | Token | Size  |
| ----- | ---- | ----- | ----- |
| `0`   | 0px  | `5`   | 20px  |
| `0.5` | 2px  | `5.5` | 22px  |
| `1`   | 4px  | `6`   | 24px  |
| `1.5` | 6px  | `7`   | 28px  |
| `2`   | 8px  | `8`   | 32px  |
| `2.5` | 10px | `9`   | 36px  |
| `3`   | 12px | `10`  | 40px  |
| `3.5` | 14px | `12`  | 48px  |
| `4`   | 16px | `16`  | 64px  |
| `4.5` | 18px | `20`  | 80px  |

`11` (44px) and `14` (56px) complete the small end; above `20` the scale
climbs by fours — `24`, `28`, `32`, … `64` — then `72`, `80`, and `96`
(384px) for section- and page-level layout.

## Density

Every spacing token multiplies by `--density-factor`, so a subtree can switch
between compact, normal, and comfortable rhythm without touching individual
paddings. Set it with the `density` utility: `compact` (×0.75, 3px per unit),
`normal` (×1, 4px), `comfortable` (×1.25, 5px).

```tsx
css({ density: "compact" });
```

export const DensityComparison = () => {
  const densities = [
    { name: "compact", factor: "0.75" },
    { name: "normal", factor: "1" },
    { name: "comfortable", factor: "1.25" },
  ];
  return (
    <div style={{ display: "flex", gap: 24, flexWrap: "wrap", alignItems: "flex-start" }}>
      {densities.map((density) => (
        <div key={density.name} style={{ "--density-factor": density.factor }}>
          <div
            style={{
              fontFamily: token("fonts.mono"),
              fontSize: token("fontSizes.xs"),
              color: token("colors.fg.muted"),
              marginBottom: 6,
            }}
          >
            {density.name} ×{density.factor}
          </div>
          <div
            style={{
              width: 230,
              padding: token("spacing.4"),
              display: "flex",
              flexDirection: "column",
              gap: token("spacing.2"),
              border: "1px solid " + token("colors.bd.subtle"),
              borderRadius: 8,
              background: token("colors.bg.surface"),
              fontFamily: token("fonts.body"),
            }}
          >
            <div
              style={{
                fontSize: token("fontSizes.sm"),
                fontWeight: token("fontWeights.medium"),
                color: token("colors.fg.heading"),
              }}
            >
              Invite teammate
            </div>
            <div style={{ fontSize: token("fontSizes.xs"), color: token("colors.fg.muted") }}>
              Grant access to this web and its entities.
            </div>
            <div style={{ display: "flex", gap: token("spacing.2") }}>
              <span
                style={{
                  padding: token("spacing.1") + " " + token("spacing.3"),
                  borderRadius: 6,
                  background: token("colors.blue.s90"),
                  color: token("colors.blue.fg.onSolid"),
                  fontSize: token("fontSizes.xs"),
                }}
              >
                Invite
              </span>
              <span
                style={{
                  padding: token("spacing.1") + " " + token("spacing.3"),
                  borderRadius: 6,
                  border: "1px solid " + token("colors.bd.solid"),

                  fontSize: token("fontSizes.xs"),
                }}
              >
                Cancel
              </span>
            </div>
          </div>
        </div>
      ))}
    </div>
  );
};
