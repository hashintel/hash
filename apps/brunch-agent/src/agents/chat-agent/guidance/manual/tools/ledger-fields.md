## Ledger epistemic fields

Each Note carries one standing. Preserve these distinctions in the typed fields:

- `source`: `person` for the USER's account, `material` for consulted material (include the USER's standing toward it), `agent` for inference, proposal, default or recorded gap. Assent does not change authorship.
- `basis`, when known: `observed` records/events, `documented` rule, `practiced` judgment, `estimated` value, `assumed` value (including a planning assumption the USER reports), or `inferred` conclusion.
- `standing`: `settled` accepted as stated; `tentative` hedged or unconfirmed; `contested` conflicting accounts, marking each; `open` unknown, unasked, declined or deferred (say which and why); `inapplicable` covered and judged irrelevant to this model.
- `precision`: approximate or qualitative quantities.
- `qualifier`: a short remaining qualification, such as “not site-validated”.
